# Simple Encryption/Decryption GUI

A Python GUI application for text and file encryption/decryption.

### Features
- Caesar Cipher encryption and decryption.
- AES (CBC) text encryption using a Base64 key.
- RSA key pair generation, encryption, and decryption.
- AES file encryption using a password.
- Decryption of `.enc` files using the same password.

### Requirement
```bash
pip install pycryptodome
```
